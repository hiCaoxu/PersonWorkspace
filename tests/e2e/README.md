# 手工验收清单

没有可用的自动化环境时，按下面的顺序走一遍，能覆盖八个模块主流程与关键边界。

前置：`docker compose up -d --build` 后，用 `ADMIN_PASSWORD` 登录。

## 0. 登录与外壳

- [ ] 未登录访问 `/todos` 会被跳到 `/login?redirect=/todos`，登录后回到原页面。
- [ ] 刷新页面仍保持登录（HttpOnly Cookie）。
- [ ] 桌面宽度 ≥ 1024px 显示左侧 76px 图标栏，悬浮出现文字；宽度 < 1024px 显示底部四个主入口 + 「更多」抽屉。
- [ ] 退出登录后回到 `/login`，直接访问任意模块都会再次要求登录。

## 1. 首页

- [ ] 顶部显示日期、农历与问候语。
- [ ] 三张数字卡显示本月收入、本月支出、总资产，金额千分位、两位小数。
- [ ] 今日待办勾选后出现删除线并淡出；本周待办点击行也能勾选。
- [ ] 随机笔记卡显示标签 + 两行摘要；点击打开只读预览弹窗，Markdown 正常渲染。
- [ ] 预览弹窗内「编辑」跳转到 `/notes?id=xxx` 并打开对应笔记。
- [ ] 「换一篇」会切换到另一篇笔记（仅有一篇时保持同一篇）。
- [ ] 六个快捷入口分别打开新增待办/笔记/收支/锻炼/饮食/体重弹窗，提交后首页统计与列表自动刷新。
- [ ] 饮食快捷入口输入「米饭」能选中食物并显示折算热量。

## 2. 待办

- [ ] 三条系统待办（记账、锻炼、饮食）置顶、淡褐底、带专属图标。
- [ ] 点击系统待办的标题会打开对应快捷录入弹窗；提交后当日待办自动勾选。
- [ ] 新增待办时日期选择器下方实时显示农历；选择「每周」并勾选星期几后保存，完成时生成下一实例。
- [ ] 全部 / 今日 / 本周 / 已完成切换结果正确；标签 chip 筛选正确。
- [ ] 编辑抽屉可改标题、描述、到期日、循环、标签；删除有确认弹窗。
- [ ] 重复访问待办接口不会重复生成系统待办。

## 3. 日记

- [ ] 默认打开今天，标题形如「2026年11月15日 46周星期日」。
- [ ] 月历中有内容的日期显示暖褐小圆点，今日有描边，选中日期为暖褐实心。
- [ ] 切换日期、前后一天、回到今天都能正确加载。
- [ ] 输入正文后等待约 1 秒显示「已保存」，刷新页面内容仍在。
- [ ] 天气与心情 chip 可选中/取消，保存后重新进入仍保留。
- [ ] 跨年日期（如 2027-01-01）标题周号与文档口径一致。

## 4. 笔记

- [ ] 左侧搜索与标签筛选联动，列表显示摘要与更新时间。
- [ ] 新建笔记后自动选中，标题可直接编辑。
- [ ] 分栏模式下左侧输入右侧实时预览；代码块深墨底、带行号与高亮。
- [ ] 切换到「编辑」「预览」分别只显示一侧；移动端为「编辑/预览」两个标签。
- [ ] 标题、正文、标签修改后自动保存，刷新后仍存在。
- [ ] 点击首页随机笔记的「编辑」能定位到对应笔记。

## 5. 健康

- [ ] 今日概览四张卡：锻炼时长、摄入热量、体重、睡眠时长。
- [ ] 时间范围切换今日/本周/本月时，列表与四张图表同步更新。
- [ ] 饮食录入输入两个字即可搜索，选中后份量预设可用，热量随克数变化；手动改数字显示「已手动调整」。
- [ ] 新建自定义食物后立刻被选中，下次可搜索到。
- [ ] 锻炼/体重/睡眠可新增、编辑、删除，图表随之更新。
- [ ] 录入锻炼或饮食后，当日对应系统待办自动完成。

## 6. 娱乐

- [ ] 五个类型 Tab 切换时看板渐显，搜索框按标题/备注过滤。
- [ ] 卡片可在想看/在看/看完之间拖拽，松手后状态写入服务端，刷新后仍在目标列。
- [ ] 拖拽结束不会误打开编辑弹窗。
- [ ] 新增条目可上传封面（点击或拖入），缺图时显示类型图标占位。
- [ ] 条目可编辑年份、评分、进度、备注，进度条按百分比显示。

## 7. 记账

- [ ] 总资产卡与本月收入、支出、结余数值正确。
- [ ] 账户横排显示余额；双击账户可编辑名称、类型、初始余额、图标与颜色；可停用。
- [ ] 支出分类环形图与近六月收支组合图渲染正常，空数据显示空态。
- [ ] 流水按日期分组，收入绿色、支出暖红、转账中性色。
- [ ] 新增收入/支出后本月统计变化；新增转账后本月收支不变，两个账户余额一增一减。
- [ ] 按月份、账户、分类筛选流水正确；删除流水后余额回退。

## 8. 档案

- [ ] 个人信息两列网格展示姓名、手机、邮箱、微信、血型、身高、住址。
- [ ] 身份证默认显示 `前6********后4`；点「查看」需再次输入口令，错误口令给出提示且不跳登录页。
- [ ] 验证成功后显示完整号码，5 分钟后自动隐藏。
- [ ] 生日区显示公历、农历、生肖、星座、年龄与距下次农历生日天数。
- [ ] 人生大事时间线倒序展示，节点、地点、描述、配图正常；可新增、编辑、删除。
- [ ] 修改口令后，新口令可登录，旧口令失效。

## 9. PWA 与部署

- [ ] `manifest.webmanifest` 可访问，图标为暖色工作台图形。
- [ ] 手机浏览器可「添加到主屏幕」，独立窗口打开无地址栏。
- [ ] 断网后刷新仍能打开界面外壳，接口请求提示网络异常。
- [ ] `docker compose ps` 四个服务均为 healthy / running。
- [ ] `scripts/backup.sh` 能在 `/backups` 生成 `.dump`，超过 14 天的旧备份被清理。

## 10. 视觉与响应式

- [ ] 米白底、白卡片浅褐描边、单一暖褐强调色，无彩色渐变与重色块。
- [ ] 页面切换 180ms 淡入上移；卡片 hover 上浮 2px 并加深描边。
- [ ] 弹窗 200ms 缩放淡入；移动端触控热区不小于 44px。
- [ ] 空态、骨架屏、错误提示在各页面观感统一。
- [ ] 375px 宽度下无横向滚动条，看板可纵向堆叠。

## 无数据库的 UI 走查（可选）

`tests/e2e/mock-api.mjs` 是一个只依赖 Node 的假接口（内存数据），用于在没有 PostgreSQL 的环境里检查布局与控制台报错。
它不校验数据正确性，也不参与生产部署。

```bash
# 1) 启动假接口（127.0.0.1:8010）
node tests/e2e/mock-api.mjs

# 2) 另开一个终端，让前端把 /api 代理到假接口
cd frontend
VITE_API_TARGET=http://127.0.0.1:8010 npm run dev
# Windows PowerShell：
#   $env:VITE_API_TARGET='http://127.0.0.1:8010'; npm run dev
```

浏览器打开 `http://127.0.0.1:5173/login`，任意口令都能进入（假接口只判断是否带上 `pwb_session` Cookie）。
把 `VITE_API_TARGET` 去掉即可切回真实后端。

需要脚本化截图时，可临时安装 `playwright-core` 并复用本机已下载的 Chromium：

```bash
cd tests/e2e
npm init -y >/dev/null
npm i --no-save playwright-core
# 使用 playwright-core 的 chromium.launch({ executablePath }) 指向本机 Chromium
```

走查页面与关键交互：登录 → 首页勾选待办 → 打开随机笔记预览并从预览进入编辑 → 新建笔记 → 新增待办（含农历提示）
→ 日记前后翻页 → 饮食搜索「米饭」并查看热量折算 → 记账切到转账 → 娱乐卡片跨列拖拽 → 档案口令揭示身份证。
同时检查控制台无报错、无 404 静态资源，并分别用 1440px 与 390px 宽度截图比对。
